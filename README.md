# Ronix Studios Script Tracker

Popular Roblox games (10K+ players) that don't have a Ronix script yet. When a script is done, the developer attaches a screenshot as proof and the game is marked finished.

Live page: https://dancingunicornlol.github.io/ronix-tracker/

## How it works

- Every card links to the game on Roblox and shows its live player count.
- A game only counts as finished once a proof image is attached (4 MB max).
- Progress is saved in your browser. **Export progress** and **Import progress** move it between devices.
- Filter by all, pending or finished games, or search by name.

## Files

- `index.html` is the whole site. There is no build step.
- `bgvideo.mp4` and `bgmusic.mp3` are the background video and music.
